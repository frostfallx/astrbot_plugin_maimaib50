# AstrBot maimai DX B50 Plugin

An AstrBot plugin for querying maimai DX B50 data from Diving-Fish or
Lxns-Network and rendering B35 + B15 result images. Optional
OpenAI-compatible LLM analysis is generated from structured score evidence,
not from an unprocessed B50 payload.

## Features

- QQ/AIOCQHTTP support through AstrBot.
- `b50` queries and AWMC/Yuzu-style B50 images.
- `info <title/alias/id>` personal score lookup.
- Song title, ID and alias lookup.
- Per-user Diving-Fish/Lxns data-source selection.
- Optional evidence-based LLM roast and push recommendations.
- Normal score queries remain available when no LLM is configured.

## Commands

| Command | Description |
| --- | --- |
| `b50` | Query the sender's B50 using the selected data source. |
| `b50 <QQ>` | Query another QQ account when the data source permits it. |
| `分析b50 [focus]` / `锐评b50 [focus]` | Generate an analysis image. |
| `info <full title/alias/song ID>` | Query the sender's scores for one song. |
| `数据源` | Show the current score source. |
| `数据源 水鱼` / `数据源 落雪` | Select Diving-Fish or Lxns. |
| `查歌 <query>` / `search <query>` | Search song titles. |
| `id <song ID>` | Show song and chart details. |
| `<alias>是什么歌` / `<alias>是啥歌` | Resolve a song alias. |
| `id <song ID>有什么别名` | List known aliases. |
| `源码` / `source` | Show the public source URL and license. |

## Installation

Place the repository in the AstrBot plugin directory and install its Python
dependencies in the AstrBot environment:

```bash
python -m pip install -r /AstrBot/data/plugins/astrbot_plugin_maimaib50/requirements.txt
```

Reload the plugin from the AstrBot WebUI after installation.

## External assets

Large game assets, covers, fonts, aliases and statistical datasets are not
included in this repository and are not licensed by this project. Obtain them
from an authorized source and place them under the AstrBot data mount:

```text
/AstrBot/data/assets/
├── font/
│   ├── ResourceHanRoundedCN-Bold.ttf
│   └── Torus SemiBold.otf
└── mai/
    ├── pic/
    └── cover/
```

The default host mount `C:\astrbot\data:/AstrBot/data` exposes this directory
to the container. A different container path can be selected with
`b50_assets_path` in the AstrBot plugin settings.

Generated B50 images retain the upstream visual-design attribution:

```text
Designed by Yuri-YuzuChaN & BlueDeer233 | Generated by AstrBot
```

Analysis images retain the OneCat layout attribution:

```text
Designed by 寒桠@OneCatBot | Generated by AstrBot
```

## Configuration

Configuration is managed by AstrBot from `_conf_schema.json`. This plugin does
not read secrets from a repository `.env` file.

| Setting | Required | Description |
| --- | --- | --- |
| `b50_assets_path` | No | External asset directory; defaults to AstrBot `data/assets`. |
| `b50_llm_url` | For analysis | OpenAI-compatible API base URL. |
| `b50_llm_key` | For analysis | LLM API key. |
| `b50_llm_model` | For analysis | Provider model name. |
| `b50_llm_max_tokens` | No | Maximum analysis output tokens. |
| `b50_llm_input_price_per_million` | No | RMB input price per million tokens. |
| `b50_llm_output_price_per_million` | No | RMB output price per million tokens. |
| `b50_moderation_model` | No | Optional moderation model. |
| `maimaidxtoken` | For complete Diving-Fish `info` | Diving-Fish developer token. |
| `lxns_dev_token` | For Lxns | Lxns developer token. |
| `lxns_api_base` | No | Lxns API base URL. |
| `maimai_alias_api` | No | Song-alias API base URL. |
| `b50_daily_limit` | No | Per-user daily analysis limit; `0` disables it. |
| `query_timeout_seconds` | No | Normal query timeout. |
| `analysis_timeout_seconds` | No | Analysis timeout. |

Never commit AstrBot configuration exports, API tokens, QQ account data,
render caches or locally downloaded assets.
